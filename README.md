# AnatelloPan Table QR / GitHub Pages

## 구성
- `index.html`: 모바일 우선 반응형 QR 관리 페이지
- `assets/logo-cropped.png`: QR 중앙 삽입용 로고
- `assets/qr/table-XX.png`: 활성 테이블별 QR PNG
- TABLE 03: 미사용
- TABLE 08 / 11: 최신 링크 반영 완료

## QR 사양
- Error Correction: H
- Quiet Zone: 4 modules
- 중앙 로고 폭: 약 50%
- 로고 주위 흰색 보호 여백 포함
- 활성 QR 10개 자동 디코딩 검증 완료

## GitHub Pages
저장소 루트에 이 폴더의 내용을 그대로 올린 뒤
Settings → Pages → Deploy from a branch → `main` / `/ (root)` 로 지정하면 됩니다.
